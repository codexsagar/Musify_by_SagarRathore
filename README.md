# 🎧 Musify

Musify is a lightweight, Spotify-inspired web-based music streaming player that brings your favorite Indian and international tracks right to your fingertips, completely ad-free. 

Presented and hosted by **Sagar Rathore**, this application is designed for a seamless, lightning-fast music experience with a clean dark/light UI.

## ✨ Key Features
* **Search & Stream:** Instantly search for any song, artist, or album powered by a custom high-performance backend.
* **Personal Library:** Like your favorite tracks and build custom playlists easily.
* **Queue & Controls:** Full-featured player controls including Shuffle, Repeat, Seek, and Queue management.
* **PWA (Progressive Web App) Ready:** Can be installed directly onto your mobile phone or desktop as a native application.
* **Theming:** Clean and responsive UI supporting both Dark and Light modes.

## 🚀 Tech Stack
* **Frontend:** HTML5, Modern CSS3, Vanilla JavaScript (ES6+ Modules)
* **Backend:** Node.js / Express proxy API (hosted on Render)
* **Storage:** HTML5 LocalStorage for persistence (playlists, liked tracks, preferences)
